# ClipForge — página pública

Página estática (um único `index.html`, sem build) do ClipForge, em inglês e português.
Usa as cores e fontes do design system oficial (tokens `--cf-*`).

Publicar no GitHub Pages: repositório público > Settings > Pages > Deploy from a branch > `main` / root.
Antes de publicar, confira o e-mail de contato na seção Contact do `index.html`.
